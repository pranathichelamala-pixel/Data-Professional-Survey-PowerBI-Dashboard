# Data Professional Survey Breakdown

Interactive Power BI dashboard built on survey responses from 630 data professionals.

## Questions answered
- Where do survey takers come from?
- How does average salary differ by job title?
- Which programming languages are most popular?
- How happy are people with work/life balance and salary?
- How hard is it to break into data?

## Tools
Power BI, Power Query

## Data cleaning
Fixed a date-format error caused by locale settings (M/D/YYYY vs D/M/YYYY) by converting the column with the English (United States) locale.
